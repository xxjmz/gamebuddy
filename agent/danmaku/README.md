# GameBuddy deterministic danmaku

弹幕运行时使用三类输入：

- Mod 当前事实：敌人、当前行动、卡牌事件和场景事件；
- 本地 Codex：只用于悬停详情中的行动效果和攻击循环，不生成独立知识弹幕；
- Agent 已经给出的建议：战斗、选牌、路线、休息处和事件选择。

AI 弹幕会异步生成短句，采用铁甲战士般直接、硬朗的口吻；游戏事实仍以 Mod 为准。弹幕不读取 B 站语料，也不使用 Ollama/Chroma 检索。

技能文案由 `action-dialogue.js` 按行动机制分类后从固定词库选择；主弹幕只显示自然台词，不显示技能类别、技能名、形容词标签或冒号。怪物称号由 `monster-identity.js` 在每场战斗开始时稳定生成。完整行动、效果、来源、攻击循环和建议通过鼠标悬停查看。
