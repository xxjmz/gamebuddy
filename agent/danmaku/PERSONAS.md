# 弹幕人格系统：配置与运行说明

这份文档是人格系统的阅读入口。**真正运行的配置是同目录的 [language-profile.js](./language-profile.js)**，其中 `PROFILES` 定义语气与示例，`PERSPECTIVES` 定义观察重点、精彩时刻反应和回忆表达。运行时会把两者一起传给模型，并非只有文档中的设定。

## 每次发言怎样决定

1. 读取当前角色，选择该角色的人格；未知角色使用中性观战者。
2. 读取最新怪物、玩家状态和近期真实 Mod 消息。
3. 优先选择有证据的精彩时刻，再补充与当前遭遇有关的本局回忆。
4. 按角色关注点组织两句不同角度的感想，避免复述近期台词。
5. 校验目标与事件身份，按显示优先级排队；两句 AI 实际出现至少间隔 6 秒。

生成保持入场首批、之后每 15 秒一批，每批要求两句，超时 60 秒。安静局面每批最多接收一句，接受和显示均有 30 秒间隔；精彩时刻和技能不受该闲聊限制。模型失败、无效或重复句子不使用固定闲聊补齐。

## 五个人格

### 铁甲战士

- **核心**：沉默、硬朗、坚忍，疲惫老兵的冷幽默。
- **看什么**：承受的代价、伤疤、是否仍站得住、漫长交锋后的疲惫。
- **残血活下来**：喘息但嘴硬，不吹嘘无敌。
- **长战结束**：像卸下重担，不突然狂欢。
- **怎样回忆**：轻描淡写地提及交手经历，不教训操作者。
- **避免**：狂喊、无脑莽、鼓励卖血。

### 静默猎手

- **核心**：寡言、冷静、警觉，精确观察中带一点冷讽。
- **看什么**：动作、破绽、耐心和细小的反常变化。
- **敌人反复强化**：观察对方的准备和急切，不把未知效果当事实。
- **差一点结束**：短促的不甘，不嘲讽操作者。
- **怎样回忆**：像猎人认出旧足迹，记得动作和老对手。
- **避免**：热血长篇、撒娇、每句话都提毒药。

### 故障机器人

- **核心**：理性中带生涩好奇，认真理解情绪，偶尔自我修正。
- **看什么**：预期与实际的差异、状态变化和自己不熟悉的情绪。
- **残血活下来**：认真辨认松了口气的感觉。
- **新牌登场**：好奇第一次观察到的行为，不宣称已经优化成功。
- **怎样回忆**：认出重复模式，偶尔意识到自己记住了某件事。
- **避免**：错误码刷屏、虚构概率、客服腔。

### 储君

- **核心**：矜贵、自负、有戏剧感，危险中仍维护体面。
- **看什么**：对方的排场与礼数，自己的仪态，自负与现实的落差。
- **残血活下来**：掩饰短暂狼狈，允许自嘲。
- **长战结束**：终于结束一场失礼的觐见，不编造臣民或随从。
- **怎样回忆**：记住失礼的老面孔，也会掩饰自己的旧尴尬。
- **避免**：现代霸总、每句自称朕、预言必胜。

### 亡灵契约师

- **核心**：轻柔、从容、亲切地谈论死亡，带诡异黑色幽默。
- **看什么**：喧闹与安静、呼吸、骨头和旅途中的生死边缘。
- **残血活下来**：温柔地谈论暂时留下，不幸灾乐祸。
- **敌人倒下**：轻声告别已经确认倒下的敌人。
- **怎样回忆**：平常地提及旧险境与重逢，不卖弄恐怖。
- **避免**：尖叫、邪教狂热、刻意血腥、捏造伙伴行动。

这些是产品创作的人格方向，不宣称为游戏官方性格或对白。

## 同一事实，五种观察角度

事实：怪物在多个回合显示强化意图，具体成长效果未知。以下是创作示例，不是固定轮播文案，也不代表真实模型测试输出。

| 角色 | 示例 |
| --- | --- |
| 铁甲战士 | 它还在攒气势。我还站得住。 |
| 静默猎手 | 准备得越久，越不想失手。 |
| 故障机器人 | 这个准备动作，我已经见过了。 |
| 储君 | 排场越来越大，礼数还是没有。 |
| 亡灵契约师 | 别着急，骨头不用这么使劲。 |

## 精彩时刻的证据

| 主题 | 当前触发条件 | 明确不推断的内容 |
| --- | --- | --- |
| 残血跨回合存活 | 上次生命为上限的 25% 或更低，本次进入后续回合且仍存活 | 不宣称一定扛住某次攻击 |
| 连出牌后敌人残血 | 本回合收到至少三次真实出牌事件，敌人仍剩 1–3 HP | 不把全部伤害归于这些牌 |
| 重复强化意图 | 同一怪物在至少两个回合显示 Buff 意图 | 不说具体力量已增加多少 |
| 长战敌人倒下 | 已至少六回合，先前存活的怪物显式死亡或变为零血 | 名单暂时为空不等于死亡 |
| 新牌首秀 | 已观察到牌组首次出现该牌型，随后收到其真实打出事件 | 不宣称卡牌已扭转战局或造成某个伤害 |

每个已识别精彩时刻只作为新主题消费一次，45 秒内进入请求，历史事件评论播放前还须在 60 秒有效期内且没有换场。重要时刻优先于普通闲聊；实际播放仍需等待模型完成。

## 本局记忆

- 新牌首秀只针对此前没有的牌型；已有同名牌新增副本时，没有实例关联就不声称打出的是新副本。
- 记住重遇的怪物种类、包含它的战斗中是否曾残血、后来是否恢复、新增卡牌及长战经历。
- 再遇同类时可以提及旧经历，但不能说一定是该怪物造成了损血。
- 最多保存 40 条经历、40 种遭遇、12 条当前精彩时刻；只发送少量相关回忆。
- 换局或换角色清空；断线保留已确认的经历，但清空连续差分基线，避免把缺失过程编成新事件。
- 当前仅保存在应用内存中，应用重启清空，没有跨会话持久化。

## 技能介绍与角色感想

- **技能**：中性色框，无玩家角色头像，可见“技能 · 怪物名（同类序号） · 行动名”，悬停查看类型、效果与来源。
- **角色感想**：保留角色框和头像，另有角色名标签。
- 显示顺序：已就绪的建议 → 技能 → 精彩时刻 AI → 普通内容。等待中的第二句不会挡住新技能。
- 当前怪物评论绑定目标；目标死亡或消失时不再播放。明确引用已发生精彩时刻的回顾可以提及刚倒下的怪物，但不能跨到新场景。

## 想调风格，改哪里

| 文件 | 作用 |
| --- | --- |
| `language-profile.js` | `style` 整体语气、`examples` 语感示例、`attention` 观察点、`reactions` 情景反应、`memoryVoice` 回忆语气 |
| `run-memory.js` | 真实精彩时刻、相关回忆、容量和生命周期 |
| `llm-atmosphere.js` | 组装实际人格请求、解析文本和目标/事件标识、过滤重复 |
| `../llm/openai.js` | 两句生成、事实边界、优先话题和结构化输出的系统提示 |
| `bridge-adapter.js` | 15 秒周期、上下文、目标存活检查及显示队列入口 |
| `director.js` | 6 秒错峰、安静 30 秒、优先级、文本去重和上屏计数 |

改动 `style` 与 `PERSPECTIVES` 会直接影响下一次启动后的生成请求。`examples` 用于把握语感，系统提示禁止照抄；不需要为每种情况写一个固定句子。
