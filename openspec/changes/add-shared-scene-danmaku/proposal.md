## Why

本地观战弹幕只能由 GameBuddy 生成，玩家不能与处于相似战斗场景的其他玩家交流。需要在不暴露牌组、生命、存档或游戏控制权的前提下，提供可选加入的同场景玩家弹幕。

## What Changes

- 新增可独立部署的共享弹幕中继：客户端仅在用户明确开启后连接，发送和接收短文本消息。
- 用公开、粗粒度的场景签名匹配房间：游戏版本、角色、章节/楼层、房间类型和在场敌人集合；不发送存档、种子、手牌、生命、牌组或建议。
- 新增覆盖层内的玩家弹幕输入与来源标识；本地 Mod 事实弹幕、B 站氛围弹幕和玩家弹幕保持不同来源，不参与策略。
- 为匿名会话加入长度限制、频率限制、过期、文本过滤、屏蔽与断线降级；中继不可用时本地弹幕功能继续运行。

## Non-goals

- 不自动出牌、点击游戏、修改游戏状态或用玩家弹幕推导策略、机制、胜率或人格。
- 不实现账户体系、好友关系、历史聊天记录、跨场景回放或公开搜索。
- 不把完整游戏状态、LLM 建议、玩家记忆或 API Key 发送到共享服务。

## Capabilities

### New Capabilities

- `shared-scene-danmaku`: 用隐私最小化的场景房间匹配、发送、接收和审核规则提供可选共享玩家弹幕。

### Modified Capabilities

- 无。

## Impact

- 新增可部署的 Node WebSocket relay 与运行/环境配置。
- `main.js`、`preload.js`、`src/danmaku.*` 新增 opt-in 连接、输入、来源渲染与断线状态。
- `agent/danmaku/scene-context.js` 新增只读、不可逆的公共场景签名；不改变 Mod 协议。
- 新增 relay、客户端协议、节流和隐私边界的测试与运维文档。
