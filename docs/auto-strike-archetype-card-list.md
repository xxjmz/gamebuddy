# 铁甲「自动打击流」牌表草案

本文档只做**流派归属判断**，方便你核对：哪些牌算进自动打击流，哪些只是“顺手有用”，哪些不该抬高流派度。  
还不是最终计分权重；你确认归属后，再据此定义 100% 成熟和单卡影响。

判定主轴只有两条（来自卡面，不是臆测）：

1. **地狱狂徒**：抽到名字里带「打击」的牌时，自动对随机敌人打出该牌。
2. **完美打击**：牌组里名字带「打击」的牌越多，伤害越高。

所以流派本体是：

```text
启动（地狱狂徒）
  + 过牌循环（持续抽到打击）
  + 打击包（供启动打出 / 喂完美打击）
  + 终结输出（完美打击）
  + 让循环跑得动的能量/消耗/抽牌辅助
```

## B. 建议正式纳入流派的牌

### B1. 核心部件（没有它们就不算这个流派）

| ID | 名称 | 建议槽位 | 理由 |
| --- | --- | --- | --- |
| `HELLRAISER` | 地狱狂徒 | 启动核 | 流派定义牌；没有它只是普通打击牌组 |
| `POMMEL_STRIKE` | 剑柄打击 | 循环引擎 | 攻击 + 抽牌，同时喂启动和完美打击 |
| `PILLAGE` | 劫掠 | 循环引擎 | 连续抽到非攻击为止，是主要过牌引擎 |
| `PERFECTED_STRIKE` | 完美打击 | 输出核 | 主终结技；打击包越厚越强 |

### B2. 打击包（名字含「打击」，铁甲可直接构筑）

这些牌**本身就算流派部件**，因为同时服务地狱狂徒自动打出和完美打击成长。

| ID | 名称 | 建议权重倾向 | 理由 |
| --- | --- | --- | --- |
| `STRIKE_IRONCLAD` | 打击 | 低正 / 基础厚度 | 最基础弹药；太多会稀释，但完全没有也不现实 |
| `POMMEL_STRIKE` | 剑柄打击 | 高（兼循环） | 见上 |
| `PERFECTED_STRIKE` | 完美打击 | 高（兼输出） | 见上 |
| `TWIN_STRIKE` | 双重打击 | 中 | 名字含打击，且两次伤害；吃自动打出 |
| `SETUP_STRIKE` | 预备打击 | 中 | 名字含打击；附带回合力量，自动打出时也有价值 |
| `ASHEN_STRIKE` | 灰烬打击 | 中偏低 | 名字含打击；偏消耗路线，和本流派可共存但不是主轴 |

**不计入铁甲流派打击包**（即使名字有打击）：其他角色的打击、无色/衍生打击。它们通常不会稳定进入铁甲奖励池，也不该抬高本流派度。

### B3. 强辅助：过牌 / 能量 / 让循环继续

这些牌**不是打击**，但明显让“抽到打击 → 自动打出 → 再抽”更顺。

| ID | 名称 | 建议 | 理由 |
| --- | --- | --- | --- |
| `OFFERING` | 祭品 | **强纳入** | 费 + 抽 3，是最常见的爆发过牌 |
| `BURNING_PACT` | 燃烧契约 | **强纳入** | 消耗废牌 + 抽 2，清理稀释 |
| `BATTLE_TRANCE` | 战斗专注 | **建议新纳入** | 0 费抽 3，直接喂地狱狂徒；本回合不能再抽是代价，但仍是强过牌 |
| `SHRUG_IT_OFF` | 耸肩无视 | **建议新纳入** | 格挡 + 抽 1，便宜过牌 |
| `HEADBUTT` | 头槌 | **建议新纳入** | 把弃牌顶回抽牌堆，可重抽剑柄/劫掠/完美打击 |
| `DRUM_OF_BATTLE` | 战鼓 | **建议新纳入** | 抽 2；被消耗还回能，和消耗辅助搭配好 |
| `JUGGLING` | 杂耍 | **保留纳入** | 每回合第三张攻击复制入手，攻击流很吃 |
| `STOKE` | 添柴 | **保留纳入（有条件）** | 能重整手牌，但也有随机性；适合已成型后 |
| `BLOODLETTING` | 放血 | **建议新纳入（弱）** | 0 费换能量，帮助打出 2 费完美打击/地狱狂徒 |

### B4. 弱辅助 / 生存辅助（可算一点，但不该抬太高）

| ID | 名称 | 建议 | 理由 |
| --- | --- | --- | --- |

| `TRUE_GRIT` | 坚毅 | 可选弱纳入 | 格挡 + 消耗，轻度清理 |
| `RAGE` | 狂怒 | 可选弱纳入 | 打攻击拿格挡，和自动连打契合 |
| `FEEL_NO_PAIN` | 无惧疼痛 | 可选弱纳入 | 消耗流防；只有在你已经拿燃烧契约/添柴时才有意义 |

## C. 明确不建议算作「流派牌」的常见好牌

这些牌可以让整局更强，但**不应增加自动打击流成熟度**；拿了最多因卡组变厚给轻微稀释（0 或小负）。

| 类型 | 例子 | 为什么不算 |
| --- | --- | --- |
| 力量成长轴 | 燃烧、恶魔形态、撕裂、烙印 | 另一条铁甲主轴，不是自动打击定义 |
| 纯输出无打击名 | 愤怒、铁斩波、旋风斩、全身撞击、暴走 | 不喂完美打击，也不触发地狱狂徒关键字 |
| 纯格挡墙 | 防御、壁垒、岿然不动、血墙 | 保命牌，不推进循环 |
| 消耗爆发杀招 | 恶魔之焰、契约终结 | 消耗支线终点，不是本流派终点 |
| 随机生成攻击 | 地狱之刃 | 不稳定，且不一定生成“打击” |

原则：

```text
能赢 ≠ 属于这个流派
属于这个流派 = 让「地狱狂徒自动打打击 + 完美打击结算」更完整或更稳定
```

## D. 我对「过牌辅助能不能穷尽」的结论

**不能也不该宣称“所有辅助牌都已穷尽”。**  
能穷尽的是：

1. 铁甲卡池里，名字含「打击」的牌（可枚举）
2. 明确提供抽牌 / 回顶 / 能量 / 清手牌，并服务上述主轴的牌（可枚举并人工审核）
3. 当前代码已经计入、但归属可疑的牌（如坚定不移）——该降权或移出

建议把辅助分成三档，写进后续计分：

| 档位 | 含义 | 例子 |
| --- | --- | --- |
| S | 直接让循环成立 | 祭品、燃烧契约、战斗专注、劫掠、剑柄打击 |
| A | 稳定提高抽到打击的频率 | 耸肩无视、头槌、战鼓、杂耍、放血 |
| B | 只在特定支线有用 | 重振精神、无惧疼痛、黑暗之拥、添柴 |

只有 S/A 进入「流派成熟」清单；B 最多给少量加分，或不进 100% 必备条件。

## E. 建议你先拍板的清单

如果你认可，我建议下一版流派归属先锁这些：

**必备成熟件**

- 地狱狂徒 ≥ 1
- 循环：剑柄打击 / 劫掠达到饱和
- 完美打击 ≥ 1
- 至少 1 张 S 级过牌辅助（祭品 / 燃烧契约 / 战斗专注 之一）

**打击包计入**

- 打击、剑柄打击、双重打击、预备打击、完美打击、灰烬打击（铁甲）

**强辅助计入**

- 祭品、燃烧契约、战斗专注、耸肩无视、头槌、战鼓、杂耍、放血

**弱辅助可选**

- 痛击（额外拷贝）、重振精神、坚定不移、坚毅、狂怒、武装

**明确排除**

- 力量轴、无「打击」名的纯输出、纯墙、消耗杀招
